# Factory Reallocation & Shipping Optimization Recommendation System for Nassau Candy Distributor

## Short App Story
Nassau Candy Distributor needed a smarter way to decide where products should be sourced and shipped. This app turns logistics data into a practical decision tool by comparing current factory assignments with optimized alternatives, estimating cost and lead-time impact, and helping teams test reallocation scenarios before making changes.

## What the App Does
- Compares current factory assignments with optimization recommendations
- Shows potential savings in shipping cost and delivery time
- Supports scenario-based decision making for sourcing and logistics planning
- Presents the analysis through an interactive Streamlit dashboard

## Run the App

```bash
python -m streamlit run "Nassau_Candy_Distributor_app .py"
```

If the app is already running, open the local URL shown in the terminal, usually http://localhost:8501.
